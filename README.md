# 青简 · 刷题系统

本地运行的通用刷题系统：自建题库、分组管理、AI 生成解析、自定义时长考试。
所有题库与配置都存在本机磁盘，不依赖任何云服务；只有点了「AI 生成解析」才会把**题干 / 选项 / 答案**发给所配置的模型。

## 一、启动

双击 **`start.bat`**。

- 自动打开浏览器访问 <http://127.0.0.1:8766/>
- 关闭那个黑色命令行窗口即停止服务
- 需要 Python 3 + Flask（本机已装：Python 3.13.2 / Flask 3.1.3 / python-docx）

手动启动：

```bat
cd /d D:\mytools\刷题系统
py -3 server.py
```

## 二、目录结构

```
D:\mytools\刷题系统\
  start.bat            一键启动
  server.py            Flask 后端（题库 CRUD + 四格式导入 + 大模型代理 + 账号）
  static\index.html    前端单页（青简界面）
  题库\                题库文件，按分组分子目录
    国网备考\          分组名 = 子目录名
      国网公共与行业知识832.json
      国网计算机专业598.json
      微信PDF计算机1923.json
      回忆样题9.json
  config.json          全局大模型配置（账号未单独保存时回落使用，key 明文存本机）
  smtp.json            邮件服务配置（管理员在「07 邮件服务」页填写后生成；授权码明文存本机）
  quiz.db              本地账号库（用户 / 各自的大模型配置 / 做题进度 / 邮箱验证码），SQLite
  secret.key           会话签名密钥（首次启动自动生成；删掉会让已登录用户掉线）
```

**分组就是子目录**：题库放在 `题库\<分组>\<题库名>.json`。导入时填分组，系统自动建目录；在「管理题库」里可以随时重命名题库或移动到别的分组。重命名会同步改文件名与 JSON 内的 `name`，该题库的做题记录和收藏也会一并迁移到新 id。

## 三、界面

左侧竖排功能区：**01 刷题 / 02 题库 / 03 解析 / 04 考试 / 05 统计 / 06 我的**，管理员再多一个 **07 邮件服务**；侧栏底部是账号区（登录 / 注册 / 个人主页 / 退出）。整体为水墨风格：宣纸底、墨色字、朱砂点缀。「我的」页含账号资料、做题统计、修改密码；**SMTP 配置在独立的「07 邮件服务」页，仅管理员侧栏可见**（首次部署、库里还没有账号时该页也会放行，否则注册不出第一个管理员）。

| 区域 | 说明 |
|------|------|
| 顶部统计 | 总题量 / 已作答 / 正确率 / 收藏数 |
| 题库行 | 按分组展示；点题库切换选中，点分组名整组全选或取消 |
| 题型 / 进度 / 模式 | 题型按单选多选判断；进度按题库自带的 part 分节；模式＝顺序 / 随机 / 未做 / 错题 / 收藏 |
| 题目卡 | 右上 ☆ 收藏；单选立即判分；多选选完点「提交多选」；解析区可 AI 生成 |
| 组卷考试 | 题源（当前筛选 / 收藏题 / 错题）+ 题量 + 自填时长，到 0 自动交卷 |
| 统计 | 全量统计 + 分题库进度，可清空记录与收藏 |
| 键盘 | A–H / 1–8 选项，Enter 下一题，← → 切换，Esc 关面板 |

本地存储 key：

- `quizsys_done_v1` 做题记录（含错题本）
- `quizsys_fav_v1` 收藏
- `quizsys_banks_v1` 选中的题库
- `quizsys_exam_min_v1` 上次填的考试时长

清浏览器站点数据会清掉这些记录，但**不会影响题库文件**。

## 三·五、账号（本地）

**必须登录后才能使用。** 没有登录态时打开页面会直接停在登录页（不能关闭、Esc 也关不掉）。题库、导入、解析、考试、统计、个人资料等接口全部返回 `401 {"need_login":true}`；放行的只有登录 / 注册 / 找回密码，以及「邮件服务是否已配置」这个布尔状态（`/api/mail/status`）。邮件配置本身在登录后也**只有管理员**能读能改。

**管理员**：`users.is_admin` 标记。**第一个注册的账号自动成为管理员**；老库升级时由最早注册的账号接管。管理员侧栏会多出 **「07 邮件服务」** 页，用来配置 SMTP 并发送测试邮件，账号资料旁会标「管理员」；普通账号看不到该页，接口也会返回 `403`。首次部署（库里还没有任何账号）时，未登录也能打开「07 邮件服务」页配置 SMTP——否则没有管理员就注册不出第一个账号。

注册 / 登录后：

- **配置按账号存**：AI 接口配置写进 `quiz.db` 的 `user_llm` 表，互不串用；未单独保存过时自动回落到全局 `config.json`（「解析」页会提示当前生效的是个人配置还是全局配置）
- **进度跟账号同步**：做题记录与收藏存进 `user_progress` 表，换浏览器登录也能拿回；合并规则为做题记录取较新时间、收藏取并集
- 题库仍是全局共享的，不按账号分

实现要点：邮箱 + 密码（6–128 位）注册，密码用 werkzeug scrypt 加盐哈希存储；登录态是 Flask 签名 Cookie，签名密钥存 `secret.key`，服务重启不掉线，有效期 30 天。

**邮件服务与邮箱验证码**（入口：左侧「07 邮件服务」，仅管理员侧栏可见）：

| 项 | 说明 |
|----|------|
| 支持方式 | 直连 SMTP 发信，不依赖任何第三方服务。SSL=开后用 465 端口；不支持 SSL 时用 587 + STARTTLS |
| 常用配置 | QQ 邮箱 `smtp.qq.com` / 465 / SSL；163 `smtp.163.com` / 465 / SSL；Gmail `smtp.gmail.com` / 587 / STARTTLS（SSL 关） |
| 密码一栏 | 填邮箱的 **SMTP 授权码**，不是邮箱登录密码（QQ/163 在网页版「设置 → 账户 → POP3/SMTP 服务」里生成） |
| 生效条件 | 主机、端口、用户名、授权码、发件邮箱都齐了才算配置完成；保存后可点「发送测试邮件」验证 |
| 验证码 | **注册必须先发送并填写邮箱验证码**（验证邮箱真实性后才建账号）；找回密码同走验证码。未配置邮件服务时无法注册，也收不到验证码 |

验证码规则：6 位数字，有效期 10 分钟，60 秒内不能重复发送，最多尝试 5 次；只存 `salt$SHA-256` 哈希，校验通过后立即作废。注册流程为：填邮箱 → 点「发送验证码」→ 查收邮件 → 填验证码和密码 → 提交注册；没有有效验证码不会建账号。配置存在 `smtp.json`，授权码**明文**保存在本机，和 `config.json` 一样请不要把这个目录整体分享出去。

**修改密码**：登录后在「我的」页 → 修改密码，需填写原密码。**忘记密码**：登录框 → 「忘记密码？」→ 填邮箱 → 发送验证码 → 填验证码和 6–128 位新密码 → 重置并登录（要求管理员已经配置好邮件服务）。

## 四、导入题库

入口：题库行右侧「管理题库」→ 上方「导入题库」。
支持 **纯文本 / JSON / CSV / Word(.docx)** 四种；可以粘贴，也可以选文件（Word 必须选文件）。

### 4.1 纯文本

```
1. 以下哪项属于操作系统（ ）
A. Word
B. Linux
C. Chrome
D. Photoshop
答案：B
解析：可选，没有也行

2. 进程和线程是同一个概念。（ ）
答案：错误
```

规则：

- 题号行 `1.` `1、` `(1)` 开始新题
- 选项行 `A.` `A、` `A．`，字母须按 A、B、C… 顺序出现
- 答案行 `答案：A` / `答案:A` / `【答案】A` / `正确答案：AB`
- 解析行 `解析：…`，可缺省
- 判断题不写选项时，答案写 `正确/错误`、`对/错`、`√/×` 均可
- 只有一个字母 → 单选；多个字母 → 多选

### 4.2 JSON

```json
[
  {
    "stem": "以下哪项属于操作系统",
    "opts": {"A": "Word", "B": "Linux", "C": "Chrome", "D": "Photoshop"},
    "ans": "B",
    "type": "single",
    "exp": "可选",
    "part": "可选，用于分节"
  }
]
```

也接受 `{"name":"题库名","questions":[...]}` 外层包装。`opts` 既可以是 `{"A":"..."}` 也可以是 `[{"k":"A","v":"..."}]`。

### 4.3 CSV

带表头：

```csv
题干,选项A,选项B,选项C,选项D,答案,解析,题型
以下哪项属于操作系统,Word,Linux,Chrome,Photoshop,B,,单选
```

不带表头时按列序：`题干, A, B, C, D, 答案[, 解析][, 题型]`。UTF-8（含 BOM）与 GBK 自动识别。

### 4.4 Word (.docx)

两种写法都支持：

1. **段落**：格式与「纯文本」完全一致（题号 + 选项行 + 答案行）
2. **表格**：表头 `题干 / 选项A / 选项B / 选项C / 选项D / 答案 / 解析 / 题型`，每行一题

导入后会提示「入库 N 题，剔除 M 题」以及剔除原因（答案不在选项内、选项文本重复、多选不足两个答案、重复题等）。被剔除的不会入库。

## 五、AI 生成解析

入口：题目卡解析区的「AI 生成解析」，或工具栏「AI 解析设置」做全局配置与批量生成。

### 5.1 预设

| 预设 | 地址 | 模型 | Key |
|------|------|------|-----|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 需要，官网申请 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen3.8-27b:q2` | 不需要 |
| 自定义 | 任意 OpenAI 兼容地址 | 自填 | 视服务而定 |

任何 OpenAI 兼容接口（vLLM、OneAPI、硅基流动等）都可以用「自定义」。

### 5.2 本地模型注意事项

本机 Ollama 的模型目录不在默认位置，启动服务时必须带环境变量，否则 `/api/tags` 会是空的、页面报「模型不存在」：

```bat
set OLLAMA_MODELS=D:\mytools\ollama\models
ollama serve
```

先在命令行确认模型在：

```bat
ollama list
curl http://127.0.0.1:11434/v1/models
```

再在页面「AI 解析设置」选「本地 Ollama」→ 保存并测试。本地 27B 模型生成一条解析通常十几秒到一分钟，属正常。

**思维模型（Qwen3 等）注意：** 这类模型先「想」再「答」，思考会吃掉整个 token 预算，表现为返回空内容、`finish_reason=length`。后端对本地地址会自动带 `reasoning_effort: "none"` 关闭思考（不认该参数的版本会退回不带重试）。若仍报「思考超长，正文被截断」，重试一次或换非思维模型。关闭思考后本机实测约 22 秒/题。

### 5.3 批量生成

「AI 解析设置」→ 批量生成：对**当前选中题库**里没有解析的题逐条生成，每条生成后立即写回该题库 JSON 文件，中途失败会停下并提示原因。可设置本次上限、可随时停止。

### 5.4 隐私

只发送：题干、选项、正确答案。
不发送：你的做题记录、收藏、题库名称以外的任何文件内容，也不含任何客户/业务数据。
`config.json` 里的大模型 key 与 `smtp.json` 里的邮箱授权码都以明文存在本机，请不要把这个目录整体分享出去。邮箱只用于发送验证码邮件，不做其他用途。

## 六、考试

「组卷考试」→ 选题源、题量（10/20/50/全部）、**时长（分钟，0 = 不限时）** → 开始。

- 考试中不显示对错，只记录作答
- 顶部显示倒计时，最后 60 秒变红；到 0 自动交卷
- 交卷后统一判分，错题自动写入错题本
- 结果页可「错题重考」（沿用上一次的时长）
- 考试中切换题库/筛选会提示放弃本次考试

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 打开页面空白 / 一直转圈 | 确认 `start.bat` 窗口还在；访问 <http://127.0.0.1:8766/api/banks> 看是否返回 JSON |
| 端口被占用 | 改 `server.py` 末尾 `PORT = 8766` 换成别的端口，同时改 `start.bat` 里的地址 |
| 导入后题目少了很多 | 看导入提示里的剔除原因；最常见是答案字母不在选项内、选项文本重复、题号/选项编号乱序 |
| Word 导入 0 题 | 检查是否 `A.` `B.` `C.` `D.` 顺序完整、是否有「答案：」行；表格法需表头含「题干」「答案」 |
| AI 测试失败（本地） | 见 5.2，多半是 Ollama 没带 `OLLAMA_MODELS` 启动或模型名不对 |
| AI 测试失败（DeepSeek） | 检查 key 是否有效、账户余额；错误信息会原样显示 |
| 打开页面就停在登录页、关不掉 | 这是登录门禁：不登录不能使用题库 / 解析 / 考试等任何功能。注册要求管理员已配好邮件服务并收邮箱验证码；首次部署（无账号）可在「07 邮件服务」页自行配置 |
| 刷新后进度没了 | 确认已经登录；登录后记录存 `quiz.db`。清浏览器站点数据只清本地缓存，重新登录会从账号拉回 |
| 重命名题库后旧记录还在吗 | 在。重命名会同步迁移该题库的做题记录与收藏键（本机与服务端都迁），无需手动处理 |
| 登录后过一阵掉线 | 检查 `secret.key` 是否被删或改动；该文件重命名后所有会话失效，需重新登录 |
| 忘记密码 | 联系管理员确认邮件服务已配置，再在登录框点「忘记密码？」用邮箱验证码重置；没配置邮件时只能删 `quiz.db` 中该用户（或整个文件，连进度配置一起清）后重新注册 |
| 收不到验证码 | 联系管理员打开「07 邮件服务」页确认状态为「已配置」；QQ/163 的密码一栏必须是「授权码」不是登录密码；由管理员点「发送测试邮件」看报错原文；部分邮箱需要在网页版手动开启 SMTP 服务 |
| 注册提示「邮件服务尚未配置」 | 注册必须用邮箱验证码验证真实性，请联系管理员配好 SMTP；首次部署（库里还没有账号）时可在「07 邮件服务」页自行填写（主机/端口/用户名/授权码/发件邮箱） |
| 普通账号看不到「邮件服务」页 | 这是预期行为：该页只在管理员侧栏出现，配置仅管理员可见 / 可改。第一个注册的账号自动成为管理员；老库升级时最早注册的账号接管 |
| AI 生成解析报「空内容 / 思考超长」 | 本地思维模型把预算花在思考上；见 5.2，重试或换非思维模型 |
| 题库移动分组后名字变了 | 题库 id 是「分组/文件名」，移动后 id 会变，旧路径的进度记录不再对应；同一次移动里系统会同步改 JSON 内的 group 字段 |

## 八、后端接口（自用备查）

> 除登录 / 注册 / 找回密码 / 邮件服务状态外，其余接口未登录一律返回 `401 {"need_login":true}`。邮件配置接口仅管理员可用（普通账号 `403`）；首次部署（库里还没有账号）允许未登录读写，以便配好 SMTP 后注册出第一个管理员。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/banks` | 题库摘要列表（id / name / group / 题数 / 解析数） |
| GET | `/api/bank/<id>` | 单题库完整题目（id 可含 `/`，分段 URL 编码） |
| POST | `/api/banks` | 导入（multipart：format / name / group / text / file） |
| DELETE | `/api/bank/<id>` | 删除题库文件 |
| POST | `/api/bank/<id>/group` | 移动分组，body `{"group":"..."}` |
| POST | `/api/bank/<id>/rename` | 重命名题库，body `{"name":"..."}`；同步改文件名与 JSON `name`，迁移该库的进度键，返回新 `id` |
| GET / POST | `/api/config` | 读取 / 保存大模型配置（GET 返回打码 key 与生效范围 scope：user / fallback / global） |
| POST | `/api/explain` | 生成单题解析并写回题库，body `{bank,qid,force}` |
| POST | `/api/explain/test` | 测试大模型连通性 |
| POST | `/api/auth/register` | 注册（邮箱 + 密码 + 验证码，自动登录），body `{email,password,name,code}`；`code` 必填且需先配置邮件服务 |
| POST | `/api/auth/login` | 登录，body `{email,password}` |
| POST | `/api/auth/logout` | 退出 |
| GET | `/api/auth/me` | 当前登录用户（未登录 `{user:null}`） |
| POST | `/api/auth/send-code` | 发送邮箱验证码，body `{email,purpose}`，purpose=`register` / `reset`；60 秒冷却，未配置邮件 400 |
| POST | `/api/auth/reset` | 用验证码重置密码并登录，body `{email,code,password}` |
| POST | `/api/auth/password` | 登录后修改密码，body `{old_password,new_password}` |
| GET / POST | `/api/profile` | 个人资料与统计（GET）；改称呼 body `{"name":"..."}`（POST） |
| GET | `/api/mail/status` | 只返回 `{configured, bootstrap}`：验证码能否发送、是否首次部署；无需登录 |
| GET / POST | `/api/mail/config` | **仅管理员**：读取 / 保存 SMTP 配置（GET 不返授权码，只返 `has_password`；留空密码=不修改，`clear_password:true` 清空） |
| POST | `/api/mail/test` | **仅管理员**：发送测试邮件，body `{to}`（默认发到发件邮箱） |
| GET | `/api/progress` | 拉取当前用户做题记录与收藏（未登录 401，`need_login:true`） |
| PUT | `/api/progress` | 覆盖保存当前用户进度，body `{done,fav}`（均按对象存，前端已做合并） |

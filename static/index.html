导入题库

支持纯文本、JSON、CSV 与 Word（.docx），可粘贴也可选文件。导入后按分组存放于本机题库目录。

四种格式怎么写

纯文本

1. 题干（ ）
A. 甲
B. 乙
C. 丙
D. 丁
答案：A
解析：可选，没有也行

2. 判断题题干（ ）
答案：正确

JSON

[{"stem":"题干","opts":{"A":"甲","B":"乙","C":"丙","D":"丁"},"ans":"A","type":"single","exp":"可选","part":"可选"}]

CSV

题干,选项A,选项B,选项C,选项D,答案,解析,题型
题干,甲,乙,丙,丁,A,,单选

Word

段落格式与纯文本相同（题号 + 选项行 + 答案）；
也支持表格：表头为 题干/选项A/选项B/选项C/选项D/答案/解析/题型。
